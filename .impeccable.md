# Recovo — Design Context

> Source of truth for typography, color, spacing, motion, and voice.
> Update when tokens change. Read before designing a new page or component.

## Users

Operations managers at e-commerce brands, 3PL partners, and marketplace operators. They work from laptops, in offices, mostly on desktop. They evaluate software by asking "does this save me hours per week" — not "is this pretty." They already use Shopify, Baselinker, ERPs, warehouse systems. They are NOT consumer shoppers and they are NOT buying on emotion.

**Primary job-to-be-done**: process product returns faster and recover value from them. Secondary: prove the recovery rate to a CFO.

## Brand Personality

Three adjectives, locked: **technical · confident · slightly angry**.

- **Technical** — we speak in hours saved, percent recovered, minutes per SKU. Numbers, not vibes.
- **Confident** — we assert, we don't hedge. No "maybe", no "could help you".
- **Slightly angry** — returns are a broken system. We're pissed about the waste, the hidden cost, the operational drag. That anger is fuel, not complaint.

Reference: **brand24.com** — punchy copy, data-forward, grayscale trust logos, stat blocks as design elements.
Anti-reference: the generic marketplace look (SaaS template gradients, pastel illustrations, centered stock photography, "boost your business" copy).

## Aesthetic Direction

### Typography

| Role | Family | Weights | Why |
|---|---|---|---|
| Display + body | **Geist** | 400, 500, 700 | Technical character; distinct from Inter/DM Sans; engineered feel |
| Data + labels | **Geist Mono** | 400, 500 | For numbers, percentages, SKU IDs, eyebrow labels |

Banned: Inter, DM Sans, Plus Jakarta Sans, Instrument Serif, Space Grotesk (all reflex AI-default choices).

**Usage rules**:
- All numeric data renders in Geist Mono (tabular numbers, aligned columns).
- Eyebrow labels are UPPERCASE Mono, tracking +0.08em, 11–12px.
- Display headlines use Geist 700, tight tracking (−0.02em), line-height 1.05.
- Body runs Geist 400/500 at 15–16px, line-height 1.5.

### Color System (OKLCH)

```
--bg          oklch(98%  0.005  80)   /* warm near-white */
--ink         oklch(20%  0.02   60)   /* deep warm charcoal — body text */
--ink-soft    oklch(45%  0.015  60)   /* secondary text */
--border      oklch(88%  0.01   75)   /* hairlines */
--surface     oklch(96%  0.008  75)   /* card / panel */
--accent      oklch(62%  0.185  34)   /* brand orange (~#E8512A) */
--accent-deep oklch(48%  0.19   32)   /* hover / active ember */
--accent-tint oklch(96%  0.03   40)   /* orange background wash */
--carbon      oklch(14%  0.015  60)   /* dark section background */
--carbon-ink  oklch(96%  0.005  80)   /* text on carbon */
--hazard      oklch(82%  0.14   85)   /* caution yellow — stat highlights */
```

No pure white (#FFF) or pure black (#000). Everything runs warm.

### Spacing (4pt)

```
xs  4px    /* icon-to-label */
sm  8px    /* inline */
md  16px   /* base unit */
lg  24px   /* related groups */
xl  40px   /* section inner */
2xl 64px   /* section between-blocks */
3xl 96px   /* page section */
4xl 160px  /* hero breathing room */
```

### Radius — Engineered, Not Rounded

- Buttons, inputs, cards: **2px** (not 8px, not 12px)
- Pills / tags only: full (9999px)
- Images / screenshots: 4px
- No `rounded-xl` anywhere.

### Banned patterns

- `border-left: 4px solid color` accent stripes
- Gradient text (`background-clip: text`)
- Pastel gradient blob backgrounds
- Centered hero with three supporting columns beneath
- Generic illustration packs
- `scale(0)` → `scale(1)` entry animations
- Purely decorative scroll-reveal on everything

## Layout DNA

- **Left-aligned** hero, not centered. Copy owns the left 60%, supporting data/visual owns the right 40%.
- **Asymmetric grid** — uneven column widths, deliberate white space on one side.
- **Full-bleed sections** with strong horizontal rules between them (1px `--border`, full width).
- **Max content width 1280px**, gutters 32px.
- **Data blocks as design elements** — big mono numbers (`47%`, `8.2h`, `€340`) act as headlines.
- **Carbon sections** — one or two sections per page flip to dark (`--carbon` background) to break rhythm. Used for the Recommerce callout and final CTA.

## Motion (emil-design-eng alignment)

- Default easing: `cubic-bezier(0.23, 1, 0.32, 1)` — the "emil" curve.
- Default duration: 180–260ms for micro-interactions, 320–440ms for section transitions.
- Asymmetric timings: enter slower than exit (e.g. 300ms in / 180ms out).
- Hover state on CTA: `transform: translate(0, -1px)` + shadow shift. No scale.
- Never animate entry with `scale(0)`. Use `opacity + translateY(8px)` instead.
- `transform-origin` respected on every scaling element.

## Voice

**DO**:
- "Cut return-handling time by 47%."
- "Every return costs you €4.20 in labor. We fix that."
- "Operators hate broken tooling. We built this for them."
- "The old way: 14 touchpoints. The new way: 3."

**DON'T**:
- "Revolutionize your returns experience"
- "Empower your team"
- "Take your business to the next level"
- "We believe in…"

Short sentences. Second person. Numbers over adjectives. The slight anger shows up as directness — we name the pain, we don't apologize for it.

## Definition of "shipped"

A redesign is done when:
- Banned fonts/radii/patterns are gone
- Numbers render in Geist Mono
- Hero is left-aligned with right-column data/visual
- At least one carbon section per page
- Motion uses the emil curve, never `scale(0)` entries
- Copy passes the voice rules above
